里面先放了DAPO-math的7K题的数据集（AIME难度，是原来17K的缩水版），名字叫做：dapomath_7000.parquet。测试集没有，可以用它自己先代替。
里面还放了math的7.4K题的数据集（中学数学难度，比GSM8K难一些），训练集名字叫做：math_train_fixed.parquet，测试集名字叫做：math_test_fixed.parquet

上面两个数据集都已经对齐过了verl-0.6.1中sglang部分的特殊数据格式，因此不建议再自己下载，配置较繁。

如果需要全量数据，那么可以从这两个地方手动下载：
DAPO-math: https://huggingface.co/datasets/zhuzilin/dapo-math-17k
https://huggingface.co/datasets/EleutherAI/hendrycks_math
但是DAPO-math需要新建一个raw_prompt列，把prompt复制过去
math需要先新建一个raw_prompt列，按照chat-template格式把Problem放进去
math还需要一个reward_model列，先用regex把ground_truth从solution里面给抓出来，然后在reward_model里面新开一个ground_truth属性放答案
（其中math的配置很繁，不建议手动下载，可以直接用我放上去的版本）

											实验代码
==============================================================================
Code Repository URL: https://github.com/Ayanami-0123/Project1 
需要版本：
verl-0.6.1，但是实验的时候发现，a100服务器的root文件夹里面的docker虽然是0.6.0的但是也能用。
#如果使用的是verl-0.6.0版本，wandb版本较老，无法接受后面提供API key，需要手动upgrade
使用方法：
1. clone MEI分支。
2. cd verl/examples/grpo_trainer，找到grpo_auto_train.sh，它只负责断点续传
3. grpo_auto_train.sh执行的主文件，是run_qwen2_5_7b_grpo.sh；这个文件顶部有一些有关模型路径、数据路径、存储路径、VISIBLE_GPU、Batch Size的变量，这些需要手动完成配置。
4. 然后bash grpo_auto_train.sh 即可开始训练
